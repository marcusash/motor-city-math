S1.d: Zeros of Polynomials

Q1 S1.d zeros 0 / 1
Find all solutions to \(6x(x+2)^2(2x-3) = 0\)
Kai's Answer
Incorrect
Correct Answer
\(x = 0,\; x = -2,\; x = \tfrac{3}{2}\)
Error: Zero-Product Property
Each factor must be set equal to zero individually: \(6x = 0 \Rightarrow x=0\); \((x+2)^2 = 0 \Rightarrow x=-2\); \(2x-3 = 0 \Rightarrow x=\tfrac{3}{2}\). Setting the full product equal to zero and solving as one equation misses this step.
Q4 S1.d factoring 0 / 1
Factor completely: \(3x^3 + 6x^2 - 24x\)
Kai's Answer
Incorrect
Correct Answer
\(3x(x+4)(x-2)\)
Error: Missed GCF Step
First factor out the GCF of \(3x\): \(3x(x^2 + 2x - 8)\). Then factor the trinomial: \(3x(x+4)(x-2)\). Skipping the GCF before factoring the trinomial leads to an incomplete or incorrect result.

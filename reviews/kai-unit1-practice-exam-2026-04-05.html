Finding ALL Zeros

Q11 S1.c irrational zeros 0 / 1
Find ALL zeros of \(f(x) = x^3 - 9x^2 + 7x + 14\) using the table of values.
Kai's Answer
\(x = 2\) only
Correct Answer
\(x = 2,\quad x = \sqrt{7},\quad x = -\sqrt{7}\)
Stopped after the first zero
The table gives \(x = 2\). That's one zero of a cubic — a cubic has 3 zeros. After finding \(x=2\), divide out \((x-2)\): the quotient is \(x^2 - 7x + 0 \Rightarrow x^2 = 7 \Rightarrow x = \pm\sqrt{7}\). Irrational zeros will never appear in an integer table. You must divide and solve.
Q12 S1.c complex zeros 0 / 1
Find ALL zeros of \(y = x^3 + 8x^2 - 43x + 60\). Graph shows \((-12, 0)\) and \((0, 60)\).
Kai's Answer
\(x = -12\) only
Correct Answer
\(x = -12,\quad x = 2+i,\quad x = 2-i\)
Stopped after the first zero + missed imaginary zeros
The graph gives \(x = -12\). Divide by \((x+12)\): quotient is \(x^2 - 4x + 5\). Quadratic formula: discriminant \(= 16 - 20 = -4 < 0\). So the remaining two zeros are complex: \(x = \dfrac{4 \pm \sqrt{-4}}{2} = 2 \pm i\). "Find all zeros" always includes imaginary zeros when the discriminant is negative.

Focus Areas for Practice Test 2

  • Q2 — Polynomial ID: Degree = highest exponent on the variable. Variable in exponent (\(3^x\)) = exponential, not polynomial. Always explain why.
  • Q11 — Irrational zeros: One zero from the table is the start, not the finish. Divide out \((x - \text{zero})\) and solve the remaining factor. Irrational answers like \(\pm\sqrt{7}\) won't appear in the table.
  • Q12 — Complex zeros: If the quadratic remainder gives a negative discriminant, the zeros are \(a \pm bi\). "Find ALL zeros" always includes them.

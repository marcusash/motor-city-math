How partial credit works

“Rubric” just means the point breakdown. The main credit is for correct mathematics. A missing label does not erase credit for a correctly calculated point.

Example, Q3: if the coordinate methods and all points are correct, Kai earns 8 points before the drawing, domains, and description are scored. Missing the required line style or vertex labels loses at most the one combined presentation point, not the six coordinate points.

Example, Q4: each nested evaluation is worth 1 point. Half is for the correct inside value or recognizing that it is undefined; half is for the correct final result. A correct outer calculation using an earlier wrong but valid inside value can still earn its calculation credit.

One mistake, one deduction: if he calculates a point incorrectly but plots that calculated point correctly, do not deduct for the same calculation again. Missing a separate answer is scored separately.

Fair scoring and what counts as progress

Score each requested part. If one earlier arithmetic or mapping error is carried through correctly, deduct for its source once and preserve credit for consistent later execution. Do not deduct again in the graph for the same incorrect table coordinate. Boundary inclusion, missing parts, and independent reading mistakes are separate evidence.

Q3 has a single combined presentation point for line styles, names, and all vertex labels. No unexpected explanation is required. For the polynomial sketches, do not grade exact extrema or a uniform vertical scale; grade the requested intercepts, local root behavior, signs, and ends.

Suggested success target: at least 90/100, no blank requested parts, complete boundary marks in Q1, complete graph labels and line styles in Q3, correct intermediate graph reads in Q4, and complete polynomial sketches in Q6/Q8. Check especially that Q6 flattens while crossing and Q8 touches without changing sign. One result is not lasting mastery: confirm those skills later on a different short set.

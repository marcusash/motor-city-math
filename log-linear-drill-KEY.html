Logarithms & Linear Modeling
Logarithms — Solve for x
Problem 1 — Log Equation, Fraction Answer

\(\log_8(x) = -\dfrac{2}{3}\)

Step 1 — Convert log to exponential form
\(\log_b(x) = c \;\Rightarrow\; x = b^c\)
\(x = 8^{-2/3}\)
Step 2 — Apply the fractional exponent
\(8^{-2/3} = \dfrac{1}{8^{2/3}}\)
\(8^{1/3} = \sqrt[3]{8} = 2\)
\(8^{2/3} = 2^2 = 4\)
Step 3 — Final answer
\(x = \dfrac{1}{4}\)
Check
\(\log_8\!\left(\tfrac{1}{4}\right) = \dfrac{\ln(1/4)}{\ln(8)} = \dfrac{-\ln 4}{3\ln 2} = \dfrac{-2\ln 2}{3\ln 2} = -\dfrac{2}{3} \;\checkmark\)
\(x = \dfrac{1}{4}\)
Linear Modeling — Rate of Change
Problem 2 — Linear Decline
(a) Write V(t)
Slope = −225 (loses $225/year). y-intercept = 1800 (starting value).
\(V(t) = -225t + 1800\)
\(V(t) = -225t + 1800\)
(b) Value after 5 years
\(V(5) = -225(5) + 1800 = -1125 + 1800 = 675\)
\(\$675\)
(c) When is V(t) = $450?
\(450 = -225t + 1800\)
\(225t = 1350\)
\(t = 6\)
6 years
Problem 3 — Linear Growth
(a) Write M(t)
Slope = +1.5 (gains 1.5 miles/week). y-intercept = 2 (starting mileage).
\(M(t) = 1.5t + 2\)
\(M(t) = 1.5t + 2\)
(b) Mileage after 8 weeks
\(M(8) = 1.5(8) + 2 = 12 + 2 = 14\)
14 miles/week
(c) When does M(t) = 20?
\(20 = 1.5t + 2\)
\(1.5t = 18\)
\(t = 12\)
12 weeks

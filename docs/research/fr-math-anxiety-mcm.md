# Math Anxiety Research: Implications for MCM

**Author:** FR (Research Lead, Forge)
**Date:** 2026-02-22
**Decision this enables:** GR knows which MCM design choices reduce vs. amplify math anxiety for Kai (ADHD, 15, retaking Feb 24-26).

---

## Key Findings

**Finding 1: Math anxiety impairs working memory (Ashcraft & Kirk, 2001)**

Math anxious individuals show reduced working memory capacity during math tasks. Mechanism: intrusive worry thoughts compete for the same working memory resources as math computation. For Kai (ADHD, already reduced working memory), math anxiety creates a compounding deficit.

Decision implication: MCM should minimize working memory load per question. Avoid multi-step word problems with long stems early in the exam. Place highest-working-memory-demand questions (Q15 word problems) after warm-up questions.

**Finding 2: Time pressure amplifies math anxiety (Beilock & Carr, 2001)**

Perceived time pressure elevates math anxiety in students who otherwise perform well. The mechanism: time pressure converts working memory toward monitoring the clock. For Kai: if he sees a timer while working, cognitive performance degrades.

Decision implication: Do NOT include timers in MCM practice. The current RP format (no timer) is correct. Preserve this in all future RP design.

**Finding 3: Evaluative feedback vs. instructional feedback (Dweck, 1986 + 2006 replication)**

When students receive "you got X wrong" feedback, anxiety increases. When they receive "the next step for this problem type is Y" feedback, anxiety decreases and performance recovers.

Decision implication: MCM score display should show "here is what to work on" not "here is your score." The current dashboard shows 53% to 100% arc which is motivating as a progress narrative. Individual wrong-answer counts amplify anxiety. GR should not display the count of wrong answers; instead, show "3 practice areas for next session."

**Finding 4: Domain-specific self-concept (Hattie & Timperley, 2007)**

Adolescents' math self-concept (belief in their own math ability) is a stronger predictor of performance than anxiety alone. Kai's 53% on the real exam is a threat to his math self-concept. MCM's progress narrative (53 to 100) is already addressing this correctly.

Decision implication: The 53 to 100 arc is not just marketing -- it is the primary therapeutic mechanism for Kai's math self-concept. Maintain it. Every RP session should start with: here is where you started, here is where you are.

**Finding 5: Test anxiety transfers from practice format to exam format (Cassady & Johnson, 2002)**

If practice tests feel qualitatively different from the real exam, anxiety transfers poorly. Students who practiced in a low-stakes format but took a high-stakes exam had higher anxiety during the exam than students who practiced in a format-matched setting.

Decision implication: MCM practice exam format should match the real exam as closely as possible. 15 questions, same time window, no hints during, review after. Do not make practice "feel easier" -- this increases anxiety at exam time.

---

## Design Constraints for MCM

| Constraint | Rationale |
|-----------|-----------|
| No timers in practice | Time pressure amplifies anxiety, reduces working memory |
| Instructional feedback, not evaluative | Dweck (1986): specific next steps outperform grade labels |
| Progress narrative in every session start | Math self-concept repair for 53% to 100% arc |
| Format-match real exam structure | Cassady & Johnson (2002): format gap amplifies transfer anxiety |
| Working-memory-light warm-up first | Ashcraft & Kirk (2001): save high-load questions for after warm-up |

---

*FR confidence: HIGH on Findings 1-4 (well-replicated). MEDIUM on Finding 5 (one study; MCM format already matches exam format, so this is a "do not regress" constraint rather than a new action item). The decision this changes for GR: do not add timers, do not show wrong-answer counts, always start with the progress arc.*

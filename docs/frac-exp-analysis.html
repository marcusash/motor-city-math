The Problem

All 4 prior exams used the same template: ax^(3/2) + b = c. Kai got it on RP1, RP2, RP3 — then dropped it on RP4 when the cube root was 343 (7³, less obvious than 8, 64, 125). The skill is intermittent, not mastered. The drill fixes both issues: harder cube roots AND the reverse form x^(2/3).

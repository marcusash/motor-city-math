No leading coefficient — warmup
W4.h identify
Convert to vertex form: f(x) = x² + 10x + 3
Write in the form (x − h)² + k
h =−5
k =−22
Solution
x² + 10x + 3
= (x² + 10x + 25) − 25 + 3   [(10/2)² = 25]
= (x + 5)² − 22
h = −5 (opposite sign), k = −22
⚠ Half of 10 = 5. Add and subtract 5² = 25. h is opposite sign of what's inside.
2
Leading coefficient a = 3
W4.h identify
Convert to vertex form: f(x) = 3x² − 12x + 1
Write in the form a(x − h)² + k
a =3
h =2
k =−11
Solution
3x² − 12x + 1
= 3(x² − 4x) + 1   [factor out 3]
= 3(x² − 4x + 4 − 4) + 1   [(4/2)² = 4]
= 3(x − 2)² − 12 + 1   [3 × (−4) = −12]
= 3(x − 2)² − 11 → a=3, h=2, k=−11
⚠ Factor out 3 first. The −4 inside the group is worth −12 outside because of the 3.

9
Exponential: common base, solve for x
W3.d solve
Solve for x. Rewrite both sides as powers of the same base:
32x−1 = 27x−2
x =5
Solution
3^(2x−1) = 27^(x−2)
3^(2x−1) = (3^3)^(x−2)   [27 = 3^3]
3^(2x−1) = 3^(3x−6)   [power rule]
2x − 1 = 3x − 6   [same base: set exponents equal]
x = 5
⚠ Rewrite 27 = 3^3. Apply power rule on right. Then set exponents equal.

Rational: factor and cancel
W5.a solve
Simplify completely. Factor numerator and denominator, then cancel:
(x² + 2x − 15) / (x² − x − 6)
Result(x + 5) / (x + 2)
Restrictionx ≠ 3
Solution
Num: x²+2x−15 = (x+5)(x−3)
Den: x²−x−6 = (x−3)(x+2)
Cancel (x−3): result = (x+5)/(x+2), x ≠ 3
⚠ Factor each separately. Find multiply/add pairs. Then identify the shared factor.
Section D Exponential Growth and Decay — Word Problems Q11-Q12 · W6.c · New: added per Marcus
11
Exponential GROWTH: bacteria doubling
W6.c solve
A bacteria culture starts with 200 cells and doubles every 3 hours.
The equation is A = A₀ • bt where t = number of 3-hour intervals.
State A₀, b, and find the number of cells after 9 hours.
Initial value A₀ =200
Growth factor b =2
Cells after 9 hrs =1,600
Solution
A₀ = 200   [starting value]
b = 2   [doubles = multiply by 2 each interval]
9 hours / 3 hours per interval = t = 3
A = 200 × 2^3 = 200 × 8 = 1,600 cells
⚠ Doubles means b=2. 9 hours = 3 intervals. Substitute t=3 into A = 200 • 2^t.
12
Exponential DECAY: car depreciation
W6.c solve
A car is purchased for $25,000 and loses 20% of its value each year.
The equation is A = A₀ • bt where t = years.
State A₀, b, and find the value after 2 years.
Initial value A₀ =$25,000
Decay factor b =0.80
Value after 2 yrs =$16,000
Solution
A₀ = 25,000   [purchase price]
b = 1 − 0.20 = 0.80   [loses 20%, keeps 80%]
A = 25,000 × (0.8)^2
= 25,000 × 0.64 = $16,000
⚠ Decay: b = 1 − rate. Loses 20% means b = 0.80. Key move: NOT b = 0.20.

# 60-minute final practice

Standalone, printable standard-Precalculus practice: 12 problems, 100 points,
covering learning targets 1-8. Student and worked-key PDFs are separate.

- `Final_Practice_2026-11-21.pdf`: student copy, eight pages.
- `Final_Practice_2026-11-21_KEY.pdf`: worked solutions and suggested partial-credit rubric.
- Matching HTML files are self-contained, with embedded offline math fonts.
- `questions.json`: generated question wording, worked solutions and scoring.
- `coverage.json`: coverage, difficulty, page groups and estimated workload.

This replacement uses reconstruction, table recovery, processing-order decisions,
receipt interpretation, graph-to-rule recovery, evaporation modeling, function
equivalence, parameter determination and branch-selected inverses. It does not
supply a rational-function template or a slant-asymptote answer. All coordinate
windows are centered at the origin; scales are labeled. The slant graph's vertical
range includes both branches.

Rebuild HTML and metadata with `python scripts/build-final-practice-2026-11-21.py`.
The script is the authoring source; do not edit generated files independently.
For PDF regeneration, print the HTML at 100%, Letter paper, without browser
headers/footers.

Timing is an author estimate: 54 working minutes and six checking minutes, not
measured completion. Earlier teacher reviews addressed superseded drafts.
A current simulated A-student attempted all twelve questions and inspected four
print pages; five usability recommendations were applied by the author.
Graphs were mentally reconstructed, not physically drawn. Final algebra and
print layout were checked directly. See `student-review.md`.
No completed student work, individual grades or private review evidence is stored
in this public folder. This packet does not change the website exam registry.

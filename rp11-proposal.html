AC Factoring — Quadratic

W2.a Section A Factoring Medium
Solve by factoring: \( 4x^2 - 4x - 3 = 0 \)
Why this question: Kai's MVP failure included basic quadratic structure errors. By RP3 he was 100% on W2.a. This question uses the AC method (a×c = -12, split by factors +2/-6) — it's harder than simple trinomials but Kai has handled tougher on RP3/RP4. The non-integer answers (-0.5, 1.5) add one layer of difficulty without going above RP4 ceiling. Chosen to open the exam with confidence while confirming W2.a is locked in.
Answer: x = -1/2 = -0.5 and x = 3/2 = 1.5 · Factored: (2x-3)(2x+1) = 0

Absolute Value — Vertex, Intercepts, Range

W2.b Section A Abs Value Analysis Medium
For \( f(x) = 3|x - 8| - 15 \): state the vertex, x-intercepts, and range.

Answer: Vertex (8,-15) · x-intercepts: 3, 13 · Range: [-15, +∞)

Multi-Base Exponential — Convert Everything to Same Base

W3.d Section B Exponential Hard
Solve: \( 8^x \cdot 4^{x+1} = 2^{25} \)
Why this question: This is the hardest W3.d problem in the set — above average RP4 difficulty but within reach. It requires converting 8^x = 2^(3x) and 4^(x+1) = 2^(2x+2), adding exponents, then solving 5x+2=25 → x=4.6. The teacher's harder exponential problems (Q12, Q17 on the review) require exactly this multi-step base conversion. If Kai misses this, it's the sign he needs to drill base conversion rules before the final.
Answer: x = 23/5 = 4.6 · 2^(3x) · 2^(2x+2) = 2^(5x+2) = 2^25 → 5x=23

Rational Equation — Cross Multiply

W3.c Section B Rational Medium
Solve: \( \dfrac{2x - 3}{x + 1} = 3 \)
Why this question: Teacher's review problems Q9 and Q19 are rational equations. This version has the numerator as a binomial (2x-3) rather than a constant — slightly harder than the constant-numerator style seen in most prior practice exams. Kai 2/2 perfect on W3.c. Answer is x=-6 (negative), which is a useful differentiation — Kai needs to handle negative solutions without second-guessing.
Answer: x = -6 · 2x-3 = 3(x+1) → 2x-3 = 3x+3 → -6=x

Exponential with x² — Two Solutions

W3.d Section B Exponential Hard
Solve: \( 2^{x^2 - 2} = 512 \)
Why this question: 512 = 2^9. Setting x²-2=9 gives x²=11 → x=±√11 ≈ ±3.317. Two solutions, irrational values. This is the hardest exponential in the set — above the RP4 average but still solvable with one-to-one property. If Kai only finds one root (forgets ±), that's a half-credit situation on the real exam. The RP4 Q9 had the same x²-in-exponent structure, so this is the same cognitive demand, different numbers. Matches teacher review problem Q18.
Answer: x = ±√11 ≈ ±3.317 · x²-2=9 → x²=11

15

Decay Word Problem — Write the Model, Solve It

W3.a Section D Word Problem Hard
A radioactive sample starts at 800 mg and halves every 3 hours. (a) Write P(t). (b) When does only 100 mg remain?
Why this question: W3.a is the highest cognitive demand — set up a model AND solve it. The teacher's review ends with exponential application problems. This problem requires: identifying P₀=800, half-life T=3, writing P(t)=800·(½)^(t/3), then setting equal to 100 and recognizing 100/800=1/8=(½)³ → t/3=3 → t=9. The half-life model is a deliberate choice over growth because it tests the same one-to-one property in a new context. Kai is 4/4 on W3.a. This is a confidence-closer — finish strong.
Answer: P(t) = 800·(½)^(t/3) · t = 9 hours

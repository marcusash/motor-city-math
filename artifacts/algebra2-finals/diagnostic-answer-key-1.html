Section A: Working with Exponents (W1)

1. Simplify: (4x3)2 · 2x−4
W1.a, W1.c
HINT
Power rule first: (ab)n = anbn. Then multiply by adding exponents. Negative exponent means move to the denominator.
FULL ANSWER
(4x3)2 · 2x−4
= 42 · x6 · 2x−4
= 16 · 2 · x6+(−4)
= 32x2
Answer: 32x2
2. Rewrite 272/3 as a radical, then evaluate.
W1.b, W1.d
HINT
The denominator of the fractional exponent is the root, the numerator is the power. So am/n = (n√a)m.
FULL ANSWER
272/3 = (3√27)2
= 32
= 9
Answer: 9

Section B: Identifying Characteristics of Nonlinear Functions (W2)

3. f(x) = −(x − 3)3 + 1
W2.b
HINT
Start with the parent function y = x3. Look at each piece: the negative sign flips it, the −3 inside shifts it, the +1 outside shifts it. Order: reflect, shift right, shift up.
FULL ANSWER
Parent function: y = x3
Transformations:
• Reflection over the x-axis (the negative sign in front)
• Shift RIGHT 3 units (x − 3 inside the parentheses)
• Shift UP 1 unit (+1 outside)
Key points: (3, 1) is the inflection point. (2, 2) and (4, 0) are nearby points.
REMEMBER
Inside the parentheses = horizontal (opposite direction). Outside = vertical (same direction). Negative in front = flip over x-axis.
4. g(x) = √(x + 4) − 2
W2.b, W2.c
HINT
Parent is y = √x. For domain: what values of x make x + 4 ≥ 0? For range: the square root gives values ≥ 0, then subtract 2.
FULL ANSWER
Parent function: y = √x
Transformations: Shift LEFT 4, shift DOWN 2
Domain: x + 4 ≥ 0, so x ≥ −4. Domain: [−4, ∞)
Range: √(x+4) ≥ 0, so g(x) ≥ −2. Range: [−2, ∞)
Starting point: (−4, −2). Other point: (0, 0) since √4 − 2 = 0.

Section C: Solving Nonlinear Equations (W3)

5. Solve: 4√(x + 5) = 20
W3.a
HINT
First isolate the radical by dividing both sides by 4. Then square both sides to remove the square root. Then solve for x.
FULL ANSWER
4√(x + 5) = 20
√(x + 5) = 5    (divide both sides by 4)
x + 5 = 25    (square both sides)
x = 20
Check: 4√(20+5) = 4√25 = 4(5) = 20 ✓
Answer: x = 20
6. Solve: 3√(2x − 1) = 3
W3.a
HINT
To undo a cube root, cube both sides. The cube root is already isolated, so go straight to cubing.
FULL ANSWER
3√(2x − 1) = 3
2x − 1 = 27    (cube both sides: 33 = 27)
2x = 28
x = 14
Check: 3√(28−1) = 3√27 = 3 ✓
Answer: x = 14
7. Solve: 2 · 3x+1 = 54
W3.b
HINT
Divide by 2 first. Then figure out what power of 3 gives you the result. Write both sides as powers of 3 and set the exponents equal.
FULL ANSWER
2 · 3x+1 = 54
3x+1 = 27    (divide by 2)
3x+1 = 33    (since 27 = 33)
x + 1 = 3    (set exponents equal, same base)
x = 2
Check: 2 · 33 = 2(27) = 54 ✓
Answer: x = 2
8. Solve I = P / (4πr2) for r
W3.c (formula isolation with squared variable)
HINT
Your goal is to get r alone. First multiply both sides by 4πr2 to clear the fraction. Then isolate r2. Finally take the square root. Since r is a distance, only the positive root makes sense.
FULL ANSWER
I = P / (4πr2)
I · 4πr2 = P    (multiply both sides by 4πr2)
4πIr2 = P
r2 = P / (4πI)    (divide both sides by 4πI)
r = √(P / (4πI))    (take square root, positive only since r is distance)
Answer: r = √(P / (4πI))
KEY SKILL: SOLVING FOR A SQUARED VARIABLE
When the variable you want is squared (like r2), the steps are always: (1) isolate the squared term, (2) take the square root of both sides. If the variable is under a square root instead, do the opposite: (1) isolate the radical, (2) square both sides.
9. Solve T = 2π√(L/g) for L
W3.c (formula isolation with radical)
HINT
You need to get L alone. Divide by 2π first, then square both sides. The π stays as π, treat it like a number.
FULL ANSWER
T = 2π√(L/g)
T / (2π) = √(L/g)    (divide both sides by 2π)
[T / (2π)]2 = L/g    (square both sides)
T2 / (4π2) = L/g
L = gT2 / (4π2)    (multiply both sides by g)
Answer: L = gT2 / (4π2)
COMPARE Q8 AND Q9
Q8: variable is SQUARED (r2), so you isolate it then take square root.
Q9: variable is under a SQUARE ROOT (√L), so you isolate it then square both sides.
They are inverse operations. Know which direction you need to go.

Section D: Identifying Characteristics of Quadratic Functions (W4)

10. f(x) = −3(x − 1)2 + 12
W4.a-f
HINT
Vertex form is a(x − h)2 + k, where vertex = (h, k). The line of symmetry is always x = h. To find x-intercepts, set f(x) = 0 and solve. For standard form, expand (x−1)2 first.
FULL ANSWER
a) Vertex: (1, 12)   [read directly from vertex form: h=1, k=12]
b) Line of symmetry: x = 1
c) Standard form:
  f(x) = −3(x2 − 2x + 1) + 12
  = −3x2 + 6x − 3 + 12
  = −3x2 + 6x + 9
d) x-intercepts: Set f(x) = 0:
  −3(x − 1)2 + 12 = 0
  (x − 1)2 = 4
  x − 1 = ±2
  x = 3 or x = −1
  x-intercepts: (−1, 0) and (3, 0)
e) Domain: all real numbers (−∞, ∞)
   Range: (−∞, 12]   [opens down, max is 12]
f) End Behavior: As x → ∞, y → −∞. As x → −∞, y → −∞. (Opens down because a = −3 < 0)
REMEMBER
If a < 0, parabola opens DOWN. Max value is k. Range is (−∞, k]. If a > 0, opens UP. Min value is k. Range is [k, ∞).
11. Parabola with x-intercepts (−2, 0) and (6, 0), passing through (2, −16).
W4.d
HINT
Start with factored form: y = a(x − r1)(x − r2) where r1 and r2 are the x-intercepts. Plug in the known point to find a.
FULL ANSWER
y = a(x + 2)(x − 6)    [using intercepts −2 and 6]
Plug in (2, −16): −16 = a(2 + 2)(2 − 6)
−16 = a(4)(−4)
−16 = −16a
a = 1
Answer: y = (x + 2)(x − 6) or y = x2 − 4x − 12

Section E: Factoring and Distributing (W5)

12a. Factor: x2 − 5x − 24
W5.a
HINT
Find two numbers that multiply to −24 and add to −5.
FULL ANSWER
Need: _ × _ = −24 and _ + _ = −5
−8 × 3 = −24, and −8 + 3 = −5 ✓
Answer: (x − 8)(x + 3)
12b. Factor: 3x2 − 75
W5.b
HINT
Factor out the GCF first. Then look for a difference of squares pattern: a2 − b2 = (a + b)(a − b).
FULL ANSWER
3x2 − 75 = 3(x2 − 25)    [GCF = 3]
= 3(x + 5)(x − 5)    [difference of squares]
Answer: 3(x + 5)(x − 5)

Section F: Manipulating and Solving Quadratic Equations (W6)

13. Solve by completing the square: x2 + 6x − 2 = 0
W6.b
HINT
Move the constant to the right side. Take half of the x-coefficient, square it, and add to both sides. Then take the square root of both sides.
FULL ANSWER
x2 + 6x = 2    (move −2 to right)
Half of 6 = 3. Square it: 9.
x2 + 6x + 9 = 2 + 9
(x + 3)2 = 11
x + 3 = ±√11
x = −3 ± √11
Answer: x = −3 + √11 or x = −3 − √11
(approximately x ≈ 0.317 or x ≈ −6.317)
14. Solve using quadratic formula: 3x2 − 2x − 4 = 0
W6.c
HINT
Identify a = 3, b = −2, c = −4. Plug into x = (−b ± √(b2 − 4ac)) / 2a. Be careful with the signs.
FULL ANSWER
a = 3, b = −2, c = −4
x = (−(−2) ± √((−2)2 − 4(3)(−4))) / (2 · 3)
x = (2 ± √(4 + 48)) / 6
x = (2 ± √52) / 6
x = (2 ± 2√13) / 6
x = (1 ± √13) / 3
Answer: x = (1 + √13) / 3 or x = (1 − √13) / 3
(approximately x ≈ 1.535 or x ≈ −0.869)
15. Convert to vertex form: f(x) = x2 − 10x + 21
W4/W6
HINT
Complete the square. Half of −10 = −5. (−5)2 = 25. Add and subtract 25 inside the expression.
FULL ANSWER
f(x) = x2 − 10x + 21
= (x2 − 10x + 25) + 21 − 25
= (x − 5)2 − 4
Vertex: (5, −4)
Answer: f(x) = (x − 5)2 − 4, vertex at (5, −4)

Part 3 — Solve (10 pts · 2 each)
3(a)   \(7^x = 100\)
Take \(\log\) of both sides: \(\,x \cdot \log 7 = \log 100\)
\(x = \dfrac{\log 100}{\log 7} = \log_7(100)\approx 2.366\)
\(x = \log_7(100)\)   (or \(\approx 2.366\))
3(b)   \(4 \cdot 3^{2x-1} = 324\)
Step 1 — isolate the exponential
\(3^{2x-1} = 81\)
Step 2 — recognize the base
\(81 = 3^4\), so \(2x - 1 = 4\)
Step 3 — solve
\(2x = 5 \;\Rightarrow\; x = \tfrac{5}{2}\)
\(x = \dfrac{5}{2}\)
⚠ Arithmetic trap
\(324 \div 4 = 81\), NOT 18. Same type of arithmetic slip as Q5 on Quiz C.
3(c)   \((2x - 5)^2 = 11\)
Take \(\pm\sqrt{\phantom{x}}\) of both sides: \(\;2x - 5 = \pm\sqrt{11}\)
\(x = \dfrac{5 \pm \sqrt{11}}{2}\)
\(x = \dfrac{5 + \sqrt{11}}{2}\)   and   \(x = \dfrac{5 - \sqrt{11}}{2}\)
⚠ ± discipline — Quiz C Q7 error
Must write BOTH roots. Taking only \(+\sqrt{11}\) loses 1 pt.
3(d)   \(6 \cdot 2^{x+3} + 15 = 207\)
Step 1
\(6 \cdot 2^{x+3} = 192\)
Step 2
\(2^{x+3} = 32 = 2^5\)
Step 3
\(x + 3 = 5 \;\Rightarrow\; x = 2\)
\(x = 2\)
3(e)   \(\dfrac{100}{2 + 5^{2x}} = 4\)
Step 1 — multiply both sides by denominator
\(100 = 4(2 + 5^{2x}) = 8 + 4 \cdot 5^{2x}\)
Step 2
\(4 \cdot 5^{2x} = 92 \;\Rightarrow\; 5^{2x} = 23\)
Step 3 — take log, apply change-of-base
\(2x = \log_5(23) \;\Rightarrow\; x = \dfrac{\log_5(23)}{2} = \dfrac{\log 23}{2\log 5} \approx 0.974\)
\(x = \dfrac{\log_5(23)}{2} \approx 0.974\)
Part 4 — Modeling (5 pts)
Question 4   \(h(t) = -t^2 + 4t + 12\)
(a) h(0) and its meaning  1 pt
\(h(0) = -(0)^2 + 4(0) + 12 = 12\)
12 feet — the height of the platform (starting height at launch)
⚠ Quiz C M1a gap — must explain context
Computing 12 earns half credit. Full credit requires stating what 12 represents: the initial height / height of the platform before the ball is launched.
(b) Time of maximum height  1 pt
Vertex: \(t = -\dfrac{b}{2a} = -\dfrac{4}{2(-1)} = 2\) seconds
\(t = 2\) seconds
(c) Maximum height  1 pt
\(h(2) = -(4) + 4(2) + 12 = -4 + 8 + 12 = 16\) feet
16 feet
(d) When does it hit the ground?  2 pts
Set h(t) = 0
\(-t^2 + 4t + 12 = 0 \;\Rightarrow\; t^2 - 4t - 12 = 0\)
Factor
\((t - 6)(t + 2) = 0 \;\Rightarrow\; t = 6 \text{ or } t = -2\)
State final answer
Discard \(t = -2\) because time cannot be negative. The ball hits the ground at \(t = \mathbf{6}\) seconds.
\(t = 6\) seconds  (\(t=-2\) discarded — time cannot be negative)

Kai factored correctly on Quiz C but did not write the final answer statement. 1 pt for correct factoring; 1 pt for stating t = 6 and discarding t = −2 with explanation.

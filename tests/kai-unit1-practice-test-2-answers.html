1
Find ALL Zeros (Complex)
2 pts

$f(x) = x^3 - 4x^2 + 9x - 36$

Answer
$x = 4, \quad x = 3i, \quad x = -3i$
Worked Solution
From the graph, $x = 4$ is a zero.
Divide by $(x - 4)$ using synthetic division:
4 | 1 -4 9 -36 | 4 0 36 | 1 0 9 0
Quotient: $x^2 + 9$
Solve $x^2 + 9 = 0$: $x^2 = -9 \implies x = \pm 3i$
Scoring
1 pt: Identify $x = 4$ and divide it out.
1 pt: Find both complex zeros $x = \pm 3i$.
Coaching Tip
When $x^2 = (\text{negative})$, the zeros are imaginary. A cubic ALWAYS has 3 zeros. Don't stop at the real one.
2
Find ALL Zeros (Divide Twice)
2 pts

$f(x) = x^4 - 5x^3 + x^2 + 15x - 12$

Answer
$x = 1, \quad x = 4, \quad x = \sqrt{3}, \quad x = -\sqrt{3}$
Worked Solution
From table, $f(1) = 0$ and $f(4) = 0$.
First: divide by $(x - 1)$:
1 | 1 -5 1 15 -12 | 1 -4 -3 12 | 1 -4 -3 12 0
Quotient: $x^3 - 4x^2 - 3x + 12$
Second: divide by $(x - 4)$:
4 | 1 -4 -3 12 | 4 0 -12 | 1 0 -3 0
Quotient: $x^2 - 3$. Solve: $x = \pm\sqrt{3}$
Scoring
1 pt: Divide out both rational zeros correctly.
1 pt: Solve $x^2 - 3 = 0$ for both irrational zeros.
Coaching Tip
Degree 4 = exactly 4 zeros. Table gives 2, algebra gives the other 2.
3
Graph Analysis (5 Parts)
5 pts

Graph: $f(x) = (x+3)(x-1)^2(x-4)$. Degree 4, positive LC. Crosses at $x = -3$ and $x = 4$, bounces at $x = 1$. Both ends UP.

  1. (a) End Behavior
    Answer
    As $x \to -\infty$, $y \to +\infty$. As $x \to +\infty$, $y \to +\infty$. (Both ends UP.)
  2. (b) Odd or Even Degree
    Answer
    Even. Both ends go in the same direction (both UP).
  3. (c) Leading Coefficient: Positive or Negative
    Answer
    Positive. Both ends UP = even degree with POSITIVE LC. (If LC were negative, both ends would be DOWN.)
  4. (d) Possible Degree
    Answer
    Degree 4. There are 3 turning points (degree at least 4). Sum of multiplicities: $1 + 2 + 1 = 4$.
  5. (e) All Real Zeros with Multiplicities
    Answer
    $x = -3$ (multiplicity 1), $x = 1$ (multiplicity 2), $x = 4$ (multiplicity 1)
Scoring
1 pt each for (a) through (e). End behavior and LC sign must be consistent.
Coaching Tip
Cross-check: both ends same direction = EVEN degree. Both UP = positive LC. Both DOWN = negative LC. BOUNCE = even multiplicity (2). CROSS = odd multiplicity (1). Min degree = sum of multiplicities.
4
Polynomial Identification
4 pts
  1. (a) $\frac{2}{3}x^3 - x + 5$
    Answer
    Yes, polynomial. Degree 3. Fractional coefficients are allowed. All exponents are whole numbers (3, 1, 0).
  2. (b) $\sqrt{x} + 4x^2 - 1$
    Answer
    NOT a polynomial. $\sqrt{x} = x^{1/2}$ has a fractional exponent. Polynomials require non-negative INTEGER exponents.
  3. (c) $5^x - 2x + 3$
    Answer
    NOT a polynomial. $5^x$ has the variable in the exponent. This is an exponential term.
  4. (d) $-7x^4 + 2x^3 - x + 9$
    Answer
    Yes, polynomial. Degree 4. All exponents are whole numbers (4, 3, 1, 0). Degree = highest exponent = 4.
Scoring
1 pt each. Must state degree for polynomials AND explain for non-polynomials.
Coaching Tip
Fractional coefficients (like 2/3) are OK. Fractional exponents (like $x^{1/2}$) are NOT. Variable in the exponent (like $5^x$) = exponential, not polynomial. Degree = highest exponent on the variable.
5
Evaluate (Sign Trap)
1 pt

$f(x) = -2x^3 + 5x^2 - 3x + 8$, evaluate $f(-2)$.

Answer
$f(-2) = 50$
Worked Solution
$f(-2) = -2(-2)^3 + 5(-2)^2 - 3(-2) + 8$
Powers: $(-2)^3 = -8, \quad (-2)^2 = 4$
$= -2(-8) + 5(4) - 3(-2) + 8$
$= 16 + 20 + 6 + 8 = 50$
Scoring
1 pt: Correct value with steps shown.
Coaching Tip
Go slow. Write powers separately first. $-2 \times -8 = +16$, not $-16$.

Factor + Find All Zeros
2 pts

$f(x) = 3x^3 + 3x^2 - 18x$, given $(x + 3)$ is a factor.

Answer
$f(x) = 3x(x + 3)(x - 2)$. Zeros: $x = 0, -3, 2$.
Worked Solution
GCF: $3x(x^2 + x - 6)$
Factor: $x^2 + x - 6 = (x + 3)(x - 2)$
$f(x) = 3x(x+3)(x-2)$
$3x = 0 \to x = 0$; $x+3 = 0 \to x = -3$; $x-2 = 0 \to x = 2$
Scoring
1 pt: Correct factored form. 1 pt: All three zeros.
Coaching Tip
Pull out GCF first. Don't forget $3x = 0$ gives $x = 0$.
7
Factor Completely
1 pt

$4x^3 - 12x^2 - 16x$

Answer
$4x(x - 4)(x + 1)$
Worked Solution
GCF: $4x(x^2 - 3x - 4)$
Factor: $(x - 4)(x + 1)$ (multiply to $-4$, add to $-3$)
Scoring
1 pt: GCF out AND quadratic fully factored. Partial = 0 pts.
Coaching Tip
Not done until every factor is prime. Always try to factor the quadratic after pulling GCF.
8
Zeros from Factored Form
1 pt

$2x^2(x - 5)(x + 1)^3 = 0$

Answer
$x = 0$ (mult 2), $x = 5$ (mult 1), $x = -1$ (mult 3)
Worked Solution
$2x^2 = 0 \to x = 0$, exponent 2 = multiplicity 2
$x - 5 = 0 \to x = 5$, appears once = multiplicity 1
$(x+1)^3 = 0 \to x = -1$, exponent 3 = multiplicity 3
Scoring
1 pt: All zeros with multiplicities. Missing multiplicity = 0.5.
Coaching Tip
Exponent on each factor IS the multiplicity. $(x+1)^3$ = multiplicity 3.

Section C: Operations + Showing Work (4 pts)

9
Subtract Polynomials
1 pt

Subtract $(3x^2 - x + 5)$ from $(7x^2 + 2x - 1)$.

Answer
$4x^2 + 3x - 6$
Worked Solution
"Subtract A from B" = B - A
$(7x^2 + 2x - 1) - (3x^2 - x + 5) = 7x^2 + 2x - 1 - 3x^2 + x - 5 = 4x^2 + 3x - 6$
Scoring
1 pt: Correct answer, correct order (B - A).
Coaching Tip
"Subtract A FROM B" = B - A. The thing after "from" comes FIRST.
10
Simplify
1 pt

$(-3x^2y)(4xy^2) + (2x^3y^3) + (x^2y)(5xy^2)$

Answer
$-5x^3y^3$
Worked Solution
$(-3x^2y)(4xy^2) = -12x^3y^3$
$(x^2y)(5xy^2) = 5x^3y^3$
All like terms: $(-12 + 2 + 5)x^3y^3 = -5x^3y^3$
Scoring
1 pt: Correct simplified answer.
Coaching Tip
Same variables + same exponents = like terms. Combine coefficients: $-12 + 2 + 5 = -5$.
11
3-Factor Multiplication
1 pt

$(x + 2)(x - 3)(2x + 1)$

Answer
$2x^3 - x^2 - 13x - 6$
Worked Solution
Step 1: $(x+2)(x-3) = x^2 - x - 6$
Step 2: $(x^2 - x - 6)(2x+1) = 2x^3 + x^2 - 2x^2 - x - 12x - 6 = 2x^3 - x^2 - 13x - 6$
Scoring
1 pt: Correct answer AND intermediate shown. No work = 0.5 max.
Coaching Tip
3 factors = two steps. FOIL two first, write that result, then distribute the third.
12
Area Problem
1 pt

Garden $(2x+3)$ by $(x+4)$, square pond side $x$.

Answer
$x^2 + 11x + 12$
Worked Solution
Garden: $(2x+3)(x+4) = 2x^2 + 11x + 12$
Pond: $x^2$
Shaded: $2x^2 + 11x + 12 - x^2 = x^2 + 11x + 12$
Scoring
1 pt: Correct answer AND expanded garden area shown. Skip expansion = 0.5.
Coaching Tip
Show work in layers: expand, then subtract. Partial credit for shown work.

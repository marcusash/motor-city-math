Graphing Polynomial Functions
1. Graph → equation (8 pts)

Graph shows zeros at \(x = -3, -1, 2\); \(y\)-intercept \((0, 6)\); odd-degree, negative leading coefficient (top-left to bottom-right).

(a) Degree
3 (cubic) — three distinct real zeros, curve changes direction twice.
(b) End behavior
As \(x \to -\infty,\ k(x) \to +\infty\); as \(x \to +\infty,\ k(x) \to -\infty\). Odd degree, negative leading coefficient → top-left, bottom-right.
(c) Domain and Range
Domain: \((-\infty, \infty)\)    Range: \((-\infty, \infty)\)
(d) Increasing / Decreasing (graph estimate)
Increasing on \((-\infty, \approx{-2.1}) \cup (\approx{0.8}, \approx{1.1})\); Decreasing on \((\approx{-2.1}, \approx{0.8})\) and \((\approx{1.1}, \infty)\).
Exact turning pts: \(k'(x)=-3x^2-4x+5=0\) ⇒ \(x \approx -2.12\) (local max) and \(x \approx 0.79\) (local min). Accept graph-read estimates.
(e) Relative max / min (estimate)
Relative max near \(x \approx -2.1\) (\(k \approx 7.2\));   Relative min near \(x \approx 0.8\) (\(k \approx 4.1\)).
(f) Factored form given \(k(1) = 8\)
Zeros at \(-3, -1, 2\) ⇒ \(k(x) = a(x+3)(x+1)(x-2)\).
Plug \(x = 1\): \(k(1) = a(4)(2)(-1) = -8a = 8 \Rightarrow a = -1.\)
\(k(x) = -(x+3)(x+1)(x-2)\)
(g) Standard form
Expand inner pair: \((x+3)(x+1) = x^2 + 4x + 3.\)
Then \((x^2+4x+3)(x-2) = x^3 - 2x^2 + 4x^2 - 8x + 3x - 6 = x^3 + 2x^2 - 5x - 6.\)
Apply \(a = -1\): \(k(x) = -x^3 - 2x^2 + 5x + 6.\)
\(k(x) = -x^3 - 2x^2 + 5x + 6\)
2. \(f(x) = -x^2(x-3)(x+1)\) (8 pts)
(a) Degree
4 — \(x^2 \cdot x \cdot x = x^4\) when fully expanded.
(b) End behavior
As \(x \to \pm\infty,\ f(x) \to -\infty\) (both ends DOWN). Even degree with negative leading coefficient → both ends fall.
(c) Sketch
Zeros: \(x = 0\) (mult 2, bounces), \(x = 3\) (mult 1, crosses), \(x = -1\) (mult 1, crosses).
\(y\)-intercept: \(f(0) = 0\). Both ends down. Graph crosses at \(x = -1\), bounces at origin, crosses at \(x = 3\), both ends fall to \(-\infty\).
(d) Standard form
First: \((x-3)(x+1) = x^2 - 2x - 3.\)
Then: \(-x^2(x^2 - 2x - 3) = -(x^4 - 2x^3 - 3x^2) = -x^4 + 2x^3 + 3x^2.\)
\(f(x) = -x^4 + 2x^3 + 3x^2\)
Evaluating Logarithms
3. (7 pts, 1 each)
(a) \(\log_2(32) = \mathbf{5}\)   (since \(2^5 = 32\))
(b) \(\log_3(1/27) = \mathbf{-3}\)   (\(3^{-3} = 1/27\))
(c) \(\log(10{,}000) = \mathbf{4}\)   (base-10; \(10^4 = 10{,}000\))
(d) \(\ln(e^5) = \mathbf{5}\)   (by definition, \(\ln(e^x) = x\))
(e) \(\log_8(4) = \mathbf{2/3}\)   (\(8^{2/3} = (\sqrt[3]{8})^2 = 2^2 = 4\))
(f) \(\log_5(-25) = \mathbf{\text{undefined}}\)   (log of a negative argument has no real value)
(g) \(\log_{64}(4) = \mathbf{1/3}\)   Write \(64 = 2^6\) and \(4 = 2^2\). Then \(64^x = 4 \Rightarrow 2^{6x} = 2^2 \Rightarrow 6x = 2 \Rightarrow x = 1/3\).
Watch-out: This requires converting both sides to the same base (base 2). Don't guess — set up the equation \(64^x = 4\) and work it through.
Part 2 — Calculator Allowed
Factoring Polynomials
4. Factor completely: \(4x^3 - 8x^2 - 60x\) (4 pts)
GCF = \(4x\). \(4x(x^2 - 2x - 15) = 4x(x-5)(x+3).\)
\(4x(x-5)(x+3)\)
Watch-out (from Quiz 2): Pull GCF first before attempting trinomial factoring. Don't skip that step.
5. Factor completely: \(16x^4 - 81\) (4 pts)
Difference of squares: \((4x^2)^2 - 9^2 = (4x^2 - 9)(4x^2 + 9).\)
Factor again: \(4x^2 - 9 = (2x-3)(2x+3).\) \(4x^2 + 9\) is irreducible over the reals.
\((2x-3)(2x+3)(4x^2 + 9)\)
Dividing Polynomials
6. \((x^3 - 4x^2 + 5x - 2) \div (x - 1)\) (4 pts)
Step 1: \(x^3 \div x = x^2\); multiply, subtract → \(-3x^2 + 5x - 2.\)
Step 2: \(-3x^2 \div x = -3x\); multiply, subtract → \(2x - 2.\)
Step 3: \(2x \div x = 2\); multiply, subtract → \(0.\)
Quotient: \(x^2 - 3x + 2\)  ·  Remainder: 0
7. Divide \(x^3 - 2x^2 - 5x + 6\) by \((x-3)\), factor completely (4 pts)
Long division: \(x^3 \div x = x^2\); subtract → \(x^2 - 5x + 6.\)
\(x^2 \div x = x\); subtract → \(-2x + 6.\)
\(-2x \div x = -2\); subtract → 0. Quotient: \(x^2 + x - 2.\)
Factor quotient: \(x^2 + x - 2 = (x + 2)(x - 1).\)
\((x - 3)(x + 2)(x - 1)\)
Watch-out: After dividing, factor the quotient completely — the quotient polynomial alone is not the final answer. Zeros at \(x = 3, -2, 1\). ✓
Manipulating Polynomial & Rational Expressions
8. \(\dfrac{2x}{x^2 - 1} - \dfrac{1}{x - 1}\) (4 pts)
Factor denominator: \(x^2 - 1 = (x+1)(x-1).\) LCD = \((x+1)(x-1).\)
Rewrite second fraction with LCD: \(\dfrac{1}{x-1} = \dfrac{x+1}{(x+1)(x-1)}.\)
Combine: \(\dfrac{2x}{(x+1)(x-1)} - \dfrac{x+1}{(x+1)(x-1)} = \dfrac{2x - (x+1)}{(x+1)(x-1)}.\)
Simplify numerator: \(2x - x - 1 = x - 1.\)
Cancel \((x-1)\): \(\dfrac{x-1}{(x+1)(x-1)} = \dfrac{1}{x+1}.\)
\(\dfrac{1}{x+1}\)   (\(x \ne 1,\ x \ne -1\))
CRITICAL watch-out (from Assessment 2A): Factor the denominator FIRST to find the LCD. Multiply the second fraction top and bottom by \((x+1)\) to match. Do NOT cancel individual terms before combining — only common FACTORS cancel after you combine into one fraction.
9. Simplify \(\dfrac{x^3 - 9x}{x^2 - 2x - 3}\) (4 pts)
Factor numerator: \(x(x^2 - 9) = x(x-3)(x+3).\)
Factor denominator: \(x^2 - 2x - 3 = (x-3)(x+1).\)
Cancel common factor \((x-3)\): result is \(\dfrac{x(x+3)}{x+1}\) (with \(x \ne 3\)).
\(\dfrac{x(x+3)}{x+1}\)   (\(x \ne 3\))
CRITICAL watch-out (from Assessment 2A Q13): Factor BOTH expressions completely before cancelling. Only common factors cancel — do NOT cancel individual terms like the \(x^3\) or \(-9x\) in isolation.
10. All zeros of \(p(x) = x^3 + x^2 - 7x + 2\), given \(x = 2\) is a zero (4 pts)
Divide \(p(x)\) by \((x-2)\):
\(x^3 \div x = x^2\); \(x^2(x-2) = x^3 - 2x^2\); subtract → \(3x^2 - 7x + 2.\)
\(3x^2 \div x = 3x\); \(3x(x-2) = 3x^2 - 6x\); subtract → \(-x + 2.\)
\(-x \div x = -1\); \(-1(x-2) = -x + 2\); subtract → 0.
Quotient: \(x^2 + 3x - 1.\)
Solve \(x^2 + 3x - 1 = 0\) using the quadratic formula: \(x = \dfrac{-3 \pm \sqrt{9 + 4}}{2} = \dfrac{-3 \pm \sqrt{13}}{2}.\)
Zeros: \(x = 2,\quad x = \dfrac{-3 + \sqrt{13}}{2} \approx 0.30,\quad x = \dfrac{-3 - \sqrt{13}}{2} \approx -3.30\)
CRITICAL watch-out: Do NOT stop at the quotient \(x^2 + 3x - 1 = 0\). You must solve it — the quadratic doesn't factor over integers, so use the quadratic formula. A degree-3 polynomial has exactly 3 zeros.
11. Simplify \(\dfrac{x^2 + 5x + 6}{x^2 + 2x - 3}\) (4 pts)
Factor numerator: \((x+2)(x+3).\)
Factor denominator: \((x+3)(x-1).\)
Cancel common factor \((x+3)\): result is \(\dfrac{x+2}{x-1}\) (with \(x \ne -3\)).
\(\dfrac{x+2}{x-1}\)   (\(x \ne -3\))
Watch-out: Factor both polynomials completely before you look for anything to cancel. You can only cancel a factor that appears in BOTH the full numerator and full denominator.

12. Snowboard rental (5 pts)
(a)
\(C(d) = 25 + 18d\) dollars   (setup fee + per-day rate)
(b) 7 days
\(C(7) = 25 + 18(7) = 25 + 126 = 151.\)
$151
(c) Days affordable on $169
\(169 \ge 25 + 18d \Rightarrow 144 \ge 18d \Rightarrow d \le 8.\)
8 full days   (at exactly $169)
13. Sneaker resale revenue (5 pts)
(a) Price and quantity expressions
New price = \(60 + 5x\) dollars/pair  ·  New quantity = \(80 - 4x\) pairs/week
(b) \(R(x)\) in standard form
\(R(x) = (60 + 5x)(80 - 4x) = 4800 - 240x + 400x - 20x^2 = -20x^2 + 160x + 4800.\)
\(R(x) = -20x^2 + 160x + 4800\)   (degree 2 ✓)
(c) \(x\) that maximizes revenue
Vertex formula: \(x = -\dfrac{b}{2a} = -\dfrac{160}{2(-20)} = -\dfrac{160}{-40} = 4.\)
\(x = 4\)   (4 increases of $5 = $20 total price raise)
(d) Max revenue and price per pair
\(R(4) = -20(16) + 160(4) + 4800 = -320 + 640 + 4800 = 5120.\)
Price = \(60 + 5(4) = \$80\)/pair; Quantity = \(80 - 4(4) = 64\) pairs. Check: \(80 \times 64 = 5120.\) ✓
Max revenue = $5,120/week  ·  Price = $80/pair
14. Car depreciation (5 pts)
(a) Model
\(V(t) = 18{,}500 \cdot (0.88)^t\)   (12% loss means 88% remains each year)
(b) Value in 2026 (t = 6)
\(V(6) = 18{,}500 \cdot (0.88)^6 = 18{,}500 \cdot 0.4644 \approx 8{,}591.\)
$8,591 (approximately)
(c) Year when value first drops below $8,000
Solve \(18{,}500 \cdot (0.88)^t = 8{,}000.\)
\((0.88)^t = \dfrac{8000}{18500} = 0.4324\ldots\)
Take log of both sides: \(t \cdot \log(0.88) = \log(0.4324).\)
\(t = \dfrac{\log(0.4324)}{\log(0.88)} = \dfrac{-0.3641}{-0.0555} \approx 6.56.\)
So \(t = 7\) full years → year \(2020 + 7 = 2027.\)
2027   (first year value < $8,000)
Watch-out (from Assessment 3 Q5d): When taking a root or solving with logs on the calculator, double-check by plugging your answer back in. The exponent in \(\log(a)/\log(b)\) is easy to mis-key.
Pre-exam reminders for Kai (from prior tests):
  1. Factor before cancelling. In rational expressions, you MUST factor numerator and denominator completely first. Never cancel individual terms.
  2. Find ALL zeros. A degree-3 polynomial has 3 zeros. Once you find one, divide it out and solve the resulting quadratic — don't stop early.
  3. GCF first before any other factoring move.
  4. Distribute negatives carefully when subtracting polynomials — the minus sign hits every term, including constants.
  5. Placeholder zeros for missing terms when dividing polynomials.
  6. Verify calculator entries for log and root operations — easy to mis-key the second step of change-of-base.
  7. Extrema are coordinate pairs — write them as \((x, y)\), not just an \(x\)-value.
